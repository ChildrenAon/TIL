# setup — 기록 환경 설치

이 레포는 기록만 모아 두는 곳이 아니라, Claude Code에서 공부하고 기록하는 방식을 함께 담고 있다. 아래 세 가지를 컴퓨터마다 `~/.claude`에 설치해야 그 컴퓨터에서도 같은 방식으로 동작한다. 레포를 받기만 해서는 적용되지 않는다.

## 설치하면 바뀌는 것

### 1. `/til` 스킬 — `~/.claude/skills/til/`

- **하는 일**: 대화 끝이나 중간에 `/til`을 치면, 그 대화에서 새로 배운 것만 골라 이 레포의 오늘 날짜 파일(`YYYY/Month/MM-DD.md`)에 올릴 초안을 만든다. 하루에 몇 번이든 쓸 수 있고, 이미 기록한 것은 다시 쓰지 않는다.
- **정리 방식**: 대화에서 내가 쓴 표현을 먼저 살리고, 개념은 "내 말로 / 정식 표현" 두 줄로 남긴다. 같은 용어는 `glossary.md`에 적힌 말을 그대로 쓴다. 그날 기록은 주제별 대제목(가장 큰 `# 정보보안`, `# ONE Student`, `# 코테`)으로 나누고, 항목마다 번호(`## 1. 전자서명`)를 붙인다. 프로젝트 항목은 문제 → 해결, 고른 이유, 버린 방법 순서다. Claude가 설명만 하고 내가 이해했는지 드러나지 않은 것은 "이해 확인 필요" 후보로 따로 보여 준다.
- **묻지 않고 바로 올린다**: 마크다운은 채팅에서 렌더되지 않아 초안 확인이 어렵기 때문에, 바로 커밋·push하고 사용자가 GitHub에서 결과를 보고 피드백한다. 고쳐 달라고 하면 고쳐서 다시 올리고, 다음 기록에도 해당하는 요청(문체, 길이, 칸 구성 등)은 [`til-style.md`](til-style.md)에 규칙으로 쌓아 다음부터 처음부터 그렇게 쓴다. (`/til 모아`만 예외로 확인받는다.) 이 파일은 레포에 있어서 다른 컴퓨터에도 `git pull`만으로 반영된다.
- **`/til 모아`**: 다른 세션에서 `/til` 없이 넘어간 대화가 있으면 직접 쳐서 모은다. 이 컴퓨터의 다른 세션들(개발·수업 등)을 훑어 새로 배운 것만 골라 초안을 보여 주고, 확인받은 뒤 올린다. 공부와 관계없는 대화는 통째로 건너뛴다. 세션 기록을 읽는 스크립트는 [`collect-sessions.js`](collect-sessions.js)(Node 필요)이고, 마지막으로 모은 시각을 `~/.claude/til-collect-state.json`에 적는다.
- **공개 레포**: 학교 답변 원문·운영 값·키·개인정보·팀원 실명은 빼고 쓴다.
- **왜**: 멘토 조언(문제와 해결, 왜 그 방법을 골랐고 무엇을 버렸는지까지 회고)을 꾸준히 남기기 위해서. 정리는 Claude가 맡아 부담을 줄이되, 내가 설명할 수 있는 것만 남도록 올리기 전에 직접 확인한다.
- **이 컴퓨터에서 필요한 것**: `gh`가 ChildrenAon 계정으로 로그인돼 있어야 push된다.

### 2. 전역 규칙 — `~/.claude/CLAUDE.md`의 `TIL-SETUP` 블록

- **하는 일**: 모든 프로젝트의 Claude 세션에 적용된다.
  - **세션 이름**: 주제가 보이면 Claude가 `[분류] 주제 #PR` 형식으로 이름을 붙이고, 작업 범위가 바뀌거나 PR이 생기면 다시 붙인다. 분류는 개발 / 공부 / 문서 / 상담 / 수업 / 기타. 사용자가 "이 세션은 ○월 ○일 공부 세션이야"처럼 날짜·성격을 정해 주면 주제 없이 `[공부] 2026-11-03`만 쓴다.
  - **사이드바 그룹**: 이름을 붙일 때 맞는 그룹(ONE Student / 익산 스토어 / 수업 / 상담·취업 / 공부·기타)으로 옮긴다. 세션의 주된 작업이 바뀌면 그룹도 다시 옮긴다. 그 컴퓨터에 그룹이 없으면 처음 한 번 만든다.
  - **공부 세션 설명 방식**: 공부 세션이면 설명을 먼저 하고 모르는 곳만 꼬리 질문하며, 한 번에 한 묶음만 설명한다. 프로젝트 코드 읽기(파일을 줄 묶음 단위로, 현재 위치 먼저)와 수업 개념(내 이해를 먼저 듣고 교정) 두 갈래가 있다.
  - **틈틈이 복습**: 요일을 정하지 않고 공부 세션 중에 Claude가 복습 질문을 하나씩 끼워 넣은 뒤 하던 공부를 이어 간다. 사용자가 설명하고, 막힌 항목은 `review.md`에 남겨 다음 복습으로 넘긴다. "복습 시작"이라고 하면 연달아 낸다.
  - **답변 언어**: 설명, 표, 요약을 모두 한국어로 쓴다.
  - **메모리 동기화**: 자동 메모리는 비공개 레포로 기기 사이에 맞춘다. 설치와 사용법은 그 레포에 있다.
  - **화면 확인**: 화면을 보여 달라고 하면 그림 시안 대신 실제 코드를 띄운 화면을 보여 준다.
  - **지적과 확정 저장**: 작업 방식을 지적하거나 확정하면 Claude가 묻지 않고 그 답변에서 메모리에 저장하고 한 줄로 알린다.
- **왜**: 앱이 첫 메시지로 붙이는 이름("git pull 진행" 등)으로는 나중에 무슨 세션이었는지 알 수 없어서.
- **이 컴퓨터에서 바뀌는 것**: `CLAUDE.md`에 `<!-- TIL-SETUP:BEGIN -->` ~ `<!-- TIL-SETUP:END -->` 블록만 넣는다. 그 밖에 원래 있던 내용은 그대로 둔다. 바꾸기 전 파일은 `CLAUDE.md.bak`으로 남긴다.

### 3. 세션 이름 점검 훅 — `~/.claude/settings.json`의 `UserPromptSubmit`

- **하는 일**: 요청을 보낼 때마다 "주제가 정해지거나 바뀌었으면 이름과 그룹을 규칙대로 갱신하라"는 한 줄을 Claude에게 붙인다(`session-name-hook.txt`). 화면에는 보이지 않는다.
- **왜**: 전역 규칙만 있으면 긴 세션에서 이름 갱신을 잊을 때가 있어서, 매 요청마다 상기시킨다.
- **이 컴퓨터에서 바뀌는 것**: `settings.json`의 다른 설정과 훅은 그대로 두고 이 훅 하나만 추가한다. 이미 있으면 문구만 최신으로 맞춘다. 바꾸기 전 파일은 `settings.json.bak`으로 남긴다.

## 점검과 설치 (Windows)

```powershell
gh repo clone ChildrenAon/TIL "$HOME\Desktop\project\TIL"
cd "$HOME\Desktop\project\TIL"
powershell -ExecutionPolicy Bypass -File setup\install.ps1 -Check   # 지금 상태만 본다
powershell -ExecutionPolicy Bypass -File setup\install.ps1          # 설치
```

`-Check`는 세 항목을 `최신` / `옛 버전` / `없음`으로 보여 주고 아무것도 바꾸지 않는다. 클론 위치는 아무 곳이나 괜찮다. 설치 스크립트가 레포 경로를 스킬에 적어 둔다. 설치한 뒤에는 Claude 세션을 새로 시작한다.

Claude 세션에서 "ChildrenAon/TIL 받아 줘"라고만 해도 된다. 레포의 `CLAUDE.md`에 따라 Claude가 점검을 돌리고, 무엇이 있는지 정리해서 적용할지 먼저 묻는다.

## 되돌리기

- 스킬: `~/.claude/skills/til` 폴더를 지운다.
- 전역 규칙: `~/.claude/CLAUDE.md`에서 `TIL-SETUP` 블록을 지우거나 `CLAUDE.md.bak`으로 되돌린다.
- 훅: `~/.claude/settings.json`의 `UserPromptSubmit`에서 `[세션 이름 점검]` 항목을 지우거나 `settings.json.bak`으로 되돌린다.
- `/til 모아` 기록: `~/.claude/til-collect-state.json`을 지워도 된다.

## 규칙을 고칠 때

`~/.claude`의 파일을 직접 고치지 말고 이 레포의 `setup/`을 고친 뒤 push한다. 메모리 동기화를 설치한 컴퓨터는 세션을 시작할 때 자동으로 받아 다시 설치한다. 설치하지 않은 컴퓨터는 `git pull` 뒤 `-Check`로 `옛 버전`이 보이면 다시 설치한다.
