# TIL 스타일 규칙

`/til` 초안을 보고 고쳐 달라고 한 것 중 다음 기록에도 적용할 것을 쌓아 두는 곳이다. `/til`은 매번 이 파일을 읽고, 여기 적힌 규칙을 스킬 기본 규칙보다 먼저 따른다.

- 한 줄에 규칙 하나, 끝에 추가한 날짜를 붙인다.
- 마음이 바뀌면 줄을 지우거나 고친다. 직접 고쳐도 되고, `/til` 중에 말로 해도 된다.

## 규칙

- 간결하고 읽기 쉽게 쓴다: 칸마다 불릿은 2~4개, 한 불릿은 한 가지 사실만 짧게, 같은 말을 두 칸에 반복하지 않는다. 덜 중요한 설명·비유·부연은 뺀다. (2026-11-03)
- 인과·변화는 문장 대신 기호로 짧게 쓴다: `M↑ → 공개키 연산 횟수↑ → 속도↓`, `개인키 ✗ / 공개키 ○`. 불릿은 명사구·단문 위주 노트체. (2026-11-03)
