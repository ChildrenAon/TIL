# TIL — Today I Learned

개발하고 공부하면서 그날 새로 알게 된 것을 날짜별로 남긴다.

- **프로젝트 회고**: 직접 겪은 문제를 어떻게 풀었는지, 왜 그 방법을 골랐는지, 어떤 방법을 버렸고 왜 버렸는지
- **개념**: 공부하다가 새로 이해한 개념을 내 말로 정리한 것
- **코테**: 문제를 풀다가 새로 알게 된 것 (모든 문제를 올리지는 않는다)

## 구조

```
YYYY/Month/YYYY-MM-DD.md   하루에 파일 하나. Month는 영어 월 이름(2026/November/2026-11-03.md). 그날 배운 것을 꼬리표와 함께 쌓는다
glossary.md             용어집. 내 말로 이해한 표현과 정식 표현을 같이 둔다
setup/                  기록 도구 설정 (Claude Code /til 스킬, 설치 스크립트)
```

기록은 Claude Code와 대화하며 공부한 뒤 `/til`로 정리해 올린다. 정리할 때 대화에서 내가 쓴 표현을 먼저 살린다.

다른 컴퓨터에서 처음 받았다면 [setup/README.md](setup/README.md)를 본다. `/til` 스킬, 세션 이름 규칙, 점검 훅은 컴퓨터마다 설치해야 동작한다.
