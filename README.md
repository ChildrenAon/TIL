# TIL — Today I Learned

개발하고 공부하면서 그날 새로 알게 된 것을 날짜별로 남긴다. 하루 기록은 **주제별 대제목**으로 나눈다.

- **프로젝트** (`# ONE Student`, `# 익산 스토어`): 직접 겪은 문제를 어떻게 풀었는지, 왜 그 방법을 골랐는지, 어떤 방법을 버렸고 왜 버렸는지
- **수업 과목 · 분야** (`# 정보보안` …): 공부하다가 새로 이해한 개념을 내 말로 정리한 것
- **코테** (`# 코테`): 문제를 풀다가 새로 알게 된 것 (모든 문제를 올리지는 않는다)

하루 파일과 목차에서 대제목은 이 순서(프로젝트 → 수업 과목 → 코테)로 놓는다.

## 구조

```
YYYY/Month/MM-DD.md   하루에 파일 하나. Month는 영어 월 이름(2026/November/11-03.md)
                      맨 위 목차(색인) 아래에서 주제별 대제목(#, 가장 큰 제목)으로 나누고, 항목마다 번호(## 1. 제목)를 붙인다
projects/               프로젝트 지도. 프로젝트 대제목의 기록이 구조의 어디쯤인지 돌아와 확인하는 곳
glossary.md             용어집. 내 말로 이해한 표현과 정식 표현을 같이 둔다
setup/                  기록 도구 설정 (Claude Code /til 스킬, 설치 스크립트)
```

기록은 Claude Code와 대화하며 공부한 뒤 `/til`로 정리해 올린다. 정리할 때 대화에서 내가 쓴 표현을 먼저 살린다.

글은 맨 위 **한 줄 결론**만 읽어도 요점이 잡히고, 소제목 · 표 · 도식 · 경고 박스로 강약을 둔다. 규칙은 [setup/til-style.md](setup/til-style.md).

다른 컴퓨터에서 처음 받았다면 [setup/README.md](setup/README.md)를 본다. `/til` 스킬, 세션 이름 규칙, 점검 훅은 컴퓨터마다 설치해야 동작한다.
